# 《猫猫背包守夜》验收标准

版本：MVP 产品基线 v0.1  
负责人：ProductAgent

## 1. 验收分级

阻断级 P0：

- 无法启动、无法进入主流程。
- 数据损坏、负数货币、重复领取。
- 战斗无法结算。
- 页面出现无法返回的死路。
- 微信开发者工具无法导入或预览。

重要级 P1：

- 功能可用但状态错误。
- 红点、按钮状态、资源展示错误。
- 适配重叠影响操作。
- 广告失败状态缺失。

优化级 P2：

- 动效、文案、音效、性能细节未达最终上线品质，但不阻断 MVP 验收。

## 18. MVP 出口标准

满足以下条件才可判定第一阶段完成：

- 所有 P0 项通过。
- P1 项通过率不低于 90%，且没有影响主循环的问题。
- 登录到二次挑战的 10 分钟流程完整可录屏。
- 本地存档可恢复。
- 经济系统无负数、无重复领奖。
- QAReleaseAgent 输出剩余 P1/P2 缺陷清单和第二阶段建议。
