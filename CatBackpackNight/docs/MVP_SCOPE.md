# 《猫猫背包守夜》MVP 范围

版本：MVP 产品基线 v0.1  
负责人：ProductAgent

## 1. MVP 目标

第一阶段目标不是做完整商业服，而是交付“商业级骨架 + 可玩 MVP”。玩家必须能在微信开发者工具或真机预览中完成一条明确闭环：

登录进入游戏 -> 主页开始战斗 -> 自动战斗胜利 -> 领取奖励 -> 背包合成 -> 升级宠物或天赋 -> 再次挑战更高波次。

MVP 成功标准：

- 项目可导入微信开发者工具。
- 10 分钟内有完整可玩体验。
- 关键资源、战斗、背包、商店、宠物、天赋、任务、邮件、设置均可保存和恢复。
- 所有系统由配置驱动，后续能扩章节、商品、任务、宠物和天赋。

## 2. 版本拆分

### 2.1 第一阶段：可玩 MVP

功能范围：

- 1 个章节：黑夜森林。
- 30 个波次。
- 5 类武器。
- 5 个可用宠物。
- 1 套基础天赋树。
- 1 套每日商店。
- 每日任务、成就、邮件、设置。
- 激励广告接口占位。
- 本地存档。

体验标准：

- 所有主页面可进入、可返回、无死路。
- 战斗可以自动完成，胜利和失败都有结算。
- 资源消耗与奖励不会出现负数、重复领取、丢失。

### 2.2 第二阶段：商业化扩展

扩展范围：

- 真实微信广告接入。
- 排行榜和分享。
- 云存档或后端账号。
- 新手引导。
- 多章节和精英怪。
- 更完整技能池。
- 活动入口、签到、七日目标、限时礼包。
- 图集压缩、分包、真机性能优化。
- 上线材料、合规审核资料。

暂不承诺：

- 真实付费系统。
- 多人玩法。
- 复杂剧情系统。
- 账号跨平台迁移。

## 3. MVP 模块清单

### 3.1 登录与合规

必须实现：

- 显示登录页视觉。
- 开始游戏按钮。
- 用户协议和隐私政策勾选。
- 16+ 适龄提示。
- 健康游戏提示。
- 同意状态保存。

不做：

- 手机号授权。
- 实名认证流程。
- 后端账号。

### 3.2 主页

必须实现：

- 玩家头像、昵称、等级、经验条。
- 金币、紫钻、体力资源栏。
- 当前章节、最高波次。
- 开始战斗按钮，显示体力消耗。
- 右侧入口：任务、邮件、排行榜占位、签到占位。
- 底部导航：商店、背包、战斗、天赋、宠物。
- 设置入口。

MVP 可用假数据：

- 昵称：玩家名字七个字。
- 头像：默认猫咪头像。
- 排行榜、签到可以显示“即将开放”或占位弹窗。

### 3.3 准备战斗

必须实现：

- 当前章节和目标波次。
- 推荐战力。
- 我的战力。
- 出战武器预览。
- 开始战斗按钮。
- 返回主页。

规则：

- 开始战斗消耗 5 点体力。
- 体力不足时打开体力补充弹窗。
- 战力不足不拦截进入。

### 3.4 战斗

必须实现：

- 45 秒倒计时。
- 营地生命条。
- 怪物生成、受击、死亡。
- 5 个武器槽，武器自动冷却攻击。
- 伤害数字。
- 暂停和继续。
- 自动合成开关。
- 胜利结算。
- 失败结算。

MVP 战斗内容：

- 怪物类型至少 3 种：幽灵、骷髅、兽人或等价占位。
- 波次 1 到 30 可配置。
- 第 10、20、30 波奖励更高。
- 战斗失败给少量参与奖励，避免完全空手。

### 3.5 局内技能

必须实现：

- 一局最多弹出 1 次技能三选一。
- 3 张技能卡随机展示。
- 选择后立即生效。
- 刷新按钮支持紫钻消耗。
- 广告刷新显示占位状态。

MVP 不做：

- 多次连锁技能选择。
- 技能升级图鉴。
- 复杂技能组合。

### 3.6 背包与合成

必须实现：

- 第一页 25 个背包格。
- 物品选中和详情。
- 武器数量徽章。
- 两个同类同等级武器合成一个高一级武器。
- 开箱按钮。
- 首次合成教学弹窗。

MVP 物品：

- 剑、弓、法杖、炸弹、法球。
- 武器宝箱。
- 宠物材料。
- 蓝晶或强化石。

限制：

- 最高合成到 Lv.5。
- 背包第二、三页显示锁定或空页即可。

### 3.7 商店

必须实现：

- 每日商店页签。
- 钻石商店页签。
- 特惠礼包页签占位。
- 6 个商品卡。
- 购买扣除货币。
- 购买成功发放物品。
- 免费金币每日 1 次。
- 刷新倒计时。

MVP 商品：

- 金币包。
- 强化石。
- 宠物蛋。
- 武器宝箱。
- 紫钻兑换蓝晶。
- 体力药水。

不做：

- 真实支付。
- 限时礼包购买。
- 服务端商品刷新。

### 3.8 宠物

必须实现：

- 宠物详情展示。
- 宠物列表。
- 1 只宠物出战。
- 宠物升级。
- 已拥有、锁定、可升级、出战中状态。

MVP 宠物：

- 小黑猫。
- 幽影灵猫。
- 哈士奇。
- 熊猫侠。
- 柴犬小将。

规则：

- 升级消耗宠物材料。
- 出战宠物提供全局属性加成。
- 锁定宠物展示解锁条件。

### 3.9 天赋

必须实现：

- 攻击、防御、通用 3 个页签。
- 节点等级显示。
- 节点前置条件。
- 节点升级。
- 剩余点数。
- 重置按钮。

MVP 节点：

- 攻击力提升。
- 攻击速度提升。
- 暴击率提升。
- 暴击伤害提升。
- 营地生命提升。
- 胜利金币提升。

限制：

- 每个节点最高 3 级。
- 重置只返还天赋点，不返还其他货币，因为 MVP 不收取额外货币。

### 3.10 每日任务

必须实现：

- 每日任务列表。
- 进度条。
- 奖励展示。
- 前往、领取、已领取状态。
- 活跃度进度和 30、60、90、120 宝箱。
- 每日刷新。

MVP 任务：

- 登录游戏。
- 完成 3 次战斗。
- 合成 5 次武器。
- 击败 100 个怪物。
- 观看 1 次广告或广告占位。

### 3.11 成就

必须实现：

- 成就列表。
- 进度条。
- 奖励展示。
- 领取、前往、已领取状态。
- 一键领取。
- 总进度。

MVP 成就：

- 通关第 5 波。
- 通关第 20 波。
- 合成 100 次。
- 击败 1000 个怪物。
- 任意宠物到 10 级。

### 3.12 邮件

必须实现：

- 邮件列表。
- 邮件详情。
- 附件奖励。
- 单封领取。
- 一键领取。
- 一键删除。
- 已领取状态。
- 邮件过期提示。

MVP 邮件：

- 登录礼包。
- 维护补偿。
- 活动奖励占位。

### 3.13 设置

必须实现：

- 音乐开关。
- 音效开关。
- 震动开关。
- 省电模式开关。
- 用户协议。
- 隐私政策。
- 帮助中心占位。
- 联系客服占位。
- 当前版本号。

规则：

- 开关状态必须保存。
- 省电模式 MVP 可以降低特效数量或帧率目标，至少要有状态记录。

## 5. 后续 Agent 交接边界

UIUXAgent：

- 以设计图和 UI 模板为准实现页面结构。
- 优先保证主流程页面可用。
- 底部导航和红点必须统一。
- 宠物页按合并版实现，不拆成两个独立功能页。

AssetAgent：

- 第一阶段可用整图或占位资源。
- 需要保留资源索引名，方便后续替换为切图和图集。
- 优先提供猫、武器、怪物、按钮、货币、背景的 MVP 素材。

ClientArchAgent：

- 按 Cocos Creator 3.8 LTS/3.x + TypeScript 项目结构搭骨架。
- 提供场景路由、事件总线、存档、资源加载、时间刷新。
- 所有模块必须可 import。

GameLogicAgent：

- 先实现可跑完一局的自动战斗。
- 背包、商店、任务、成就、宠物、天赋均使用配置驱动。
- 资源变更统一走经济服务，避免负数和重复发奖。

PlatformAgent：

- MVP 先做微信 API 包装和广告接口占位。
- 第二阶段接入真实激励广告、分享、排行榜、云存档。
- 所有广告点位必须返回成功、失败、取消、无广告四类状态。

QAReleaseAgent：

- 按 `ACCEPTANCE_CRITERIA.md` 逐项验收。
- 阻断级问题优先：不能启动、不能存档、资源错误、流程死路、重复领奖。

## 6. 明确不属于 MVP 的内容

- 完整商业活动系统。
- 真实支付和礼包售卖。
- 复杂装备词条。
- 宠物升星和碎片合成深度系统。
- 多章节剧情。
- 排行榜真实数据。
- 云端邮件下发。
- 自动化 A/B 实验。
- 多语言。
