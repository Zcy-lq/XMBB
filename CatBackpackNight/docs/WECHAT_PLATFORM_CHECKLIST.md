# 微信小游戏上线检查清单

本文给第一次上线微信小游戏的同学使用。按顺序检查，能减少导入失败、广告无返回、分享不可用、排行榜不显示和合规材料缺失的问题。

## 1. 准备账号与项目

- 注册并登录微信公众平台，账号类型选择小游戏。
- 在微信公众平台后台查看小游戏 AppID。不要把 AppID、AppSecret、广告密钥写进客户端代码。
- 打开微信开发者工具，选择导入项目，目录选择 `CatBackpackNight`。
- 导入时填写后台分配的 AppID；本项目代码内不会硬编码真实 AppID。
- 确认基础库版本使用当前稳定版本，并开启 ES6 转 ES5、代码压缩等常规构建选项。

## 2. 本地预览检查

- 在 Cocos Creator 中打开 `CatBackpackNight`，确认没有脚本编译错误。
- 运行登录页，未勾选协议时点击开始游戏，应提示先同意协议。
- 勾选协议后进入主页，重启后协议状态应保留。
- 在编辑器或非微信环境中，微信登录、用户资料、广告、分享、排行榜应走 Mock，不应阻塞主流程。
- 清空本地存档后重启，默认账号和新手资源应能重新生成。

## 3. 微信登录与用户信息

- 客户端只调用 `wx.login` 获取临时 code，不在客户端换取 openId。
- 服务端上线后，用 code 在服务端换取 openId/session_key，AppSecret 只放服务端。
- 头像昵称必须由玩家主动触发授权，不要启动时强制弹授权。
- 用户拒绝授权时，游戏仍可使用默认昵称和默认头像继续体验。
- QA 需要分别验证：微信真机授权成功、拒绝授权、编辑器 Mock 三种情况。

## 4. 激励视频广告

- 在微信公众平台流量主后台创建激励视频广告位，拿到 adUnitId。
- 把 adUnitId 通过配置注入 `AdService.registerPlacement`，不要写死在业务 UI 里。
- 广告按钮文案必须明确写“看广告领取”“看广告刷新”“看广告双倍”，不要把广告奖励写成无条件免费。
- 必测四种结果：完整观看成功、中途关闭取消、播放失败、暂无广告库存。
- 成功才发放广告奖励；取消、失败、无库存都不能发放双倍奖励，但不能影响基础奖励领取。
- 达到每日广告次数上限时，按钮应禁用或提示今日已达上限。

## 5. 分享

- 调用 `ShareService.registerDefaultShare()` 后，右上角菜单分享可用。
- 主动分享按钮使用 `ShareService.shareAppMessage`。
- 分享标题、图片、query 使用配置，不要在多个 UI 文件里复制粘贴。
- 编辑器中分享会返回 Mock 结果，便于 UI 流程调试。
- 真机验证分享面板能拉起，query 不包含隐私数据、token 或真实用户身份。

## 6. 排行榜预留

- 好友排行榜需要微信开放数据域，主域只负责提交分数和发送展示消息。
- 使用 `LeaderboardService.submitHighestWave` 或 `submitScore` 写入云存储。
- 使用 `requestFriendLeaderboard` 给开放数据域发消息，开放数据域 UI 后续单独实现。
- 编辑器中会维护 Mock 排行榜，方便先做按钮和页面流程。
- 排行榜提交字段只保留分数、时间等必要数据，不上传背包、货币、手机号等敏感信息。

## 7. 本地存储与存档

- 主存档仍由 `SaveManager` 管理，平台层只封装微信 storage 和编辑器 fallback。
- 存档 key 使用 `CatBackpackNight.` 前缀，避免和其他数据冲突。
- 强退、重启、清缓存三种情况都要测试。
- 任何奖励领取、购买、升级都要先判定条件，再写存档，避免负数货币和重复领取。

## 8. 合规入口

- 登录页必须展示用户协议、隐私政策、`16+ CADPA` 适龄提示、健康游戏提示。
- 设置页必须保留用户协议、隐私政策、适龄提示、健康游戏提示入口。
- 未勾选协议不能进入主页。
- 隐私政策需要说明：微信登录 code、头像昵称授权、本地存档、广告、排行榜数据的使用方式。
- 如果后续接入支付，必须补充未成年人保护、退款说明和虚拟商品规则。

## 9. 真机与提审前

- 用至少一台低端 Android 和一台 iPhone 真机预览。
- 检查安全区：底部按钮、广告按钮、关闭按钮不能被刘海屏或 Home Indicator 遮挡。
- 断网或弱网下，登录失败、广告失败、排行榜失败要有提示，并允许继续单机体验。
- 确认构建包体、首包资源、分包策略符合微信后台要求。
- 提审前准备：游戏介绍、图标、截图、类目、隐私政策文本、用户协议文本、适龄说明、客服入口。

## 10. QA 回归建议

- P0：项目能导入微信开发者工具，登录到主页流程完整。
- P0：广告成功才发奖励；取消、失败、无库存不发广告奖励。
- P0：协议未同意时不能进入游戏。
- P1：分享、排行榜在编辑器 Mock 和微信真机均有明确返回。
- P1：震动开关关闭后不再触发微信震动。
