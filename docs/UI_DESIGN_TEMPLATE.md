# 《猫猫背包守夜》UI 设计图模板

本文档是给 Codex 多 Agent 使用的 UI 设计规范。所有 UI、素材、逻辑和测试 Agent 必须以这里为准，不能各自发挥成不同风格。

## 1. 设计目标

项目定位：竖屏微信小游戏，猫咪题材，背包合成 + 自动战斗 + 养成。

核心视觉感受：

- 可爱 Q 版，但不是低幼。
- 夜晚森林、木牌、羊皮纸、金币黄按钮组成主风格。
- 主要页面有强烈“木质冒险营地”氛围。
- 所有按钮要厚实、有描边、有按下反馈。
- 重要奖励、升级、合成、胜利要有金色发光效果。

目标分辨率：

- 设计基准：`1080 x 1920`
- 游戏逻辑坐标：`750 x 1334`
- 适配方式：等比缩放，顶部/底部安全区留白，主体内容居中。

## 3. 视觉规范

### 3.1 色彩

主色：

- 金色按钮：`#F6B332`
- 高光黄：`#FFE28A`
- 木板深棕：`#5A331F`
- 木板描边：`#2A160D`
- 羊皮纸底：`#F1D3A2`
- 深色面板：`#171A18`
- 森林夜蓝：`#071A2C`
- 成功绿色：`#67A936`
- 功能蓝：`#3186B8`
- 警告红：`#E33F2F`
- 紫钻：`#A752FF`
- 蓝钻：`#31A8FF`

使用规则：

- 黄色只用于主按钮、选中态、奖励光效。
- 绿色用于免费、领取、确认成功。
- 蓝色用于前往、刷新、次级功能。
- 红色只用于提醒、关闭、删除、红点。
- 页面背景优先用夜晚森林，不要纯色铺满。

### 3.2 字体

建议字体风格：

- 中文标题：粗圆体、白字、深棕描边。
- 数字：粗体，白色或黄色，高对比描边。
- 正文：深棕或米白，保持可读性。

实现要求：

- 微信小游戏 Canvas 中先用系统字体兜底：`sans-serif`
- 标题字号在 750 坐标下约 `44-64`
- 按钮文字约 `34-48`
- 列表正文约 `24-32`
- 数字奖励约 `30-48`

### 3.3 组件风格

基础组件：

- 木牌标题栏：页面顶部标题，左右返回/帮助/关闭按钮。
- 羊皮纸面板：任务、成就、邮件、背包详情。
- 深色战斗面板：战斗、宠物展示、准备战斗。
- 金色主按钮：开始战斗、选择、升级、确定。
- 绿色确认按钮：领取、免费、已领取状态。
- 蓝色跳转按钮：前往、刷新、功能入口。
- 商品卡片：三列网格，图片居中，价格底部绿条。
- 背包格子：5 列网格，选中格有黄色发光描边。
- 底部导航：商店、背包、战斗、天赋、宠物/设置。
- 红点提醒：圆形红底，白色 `!` 或数字。

统一细节：

- 卡片圆角：`12-20`
- 按钮圆角：`14-22`
- 面板描边：深棕双层描边
- 投影：向下偏移，颜色接近 `rgba(0,0,0,0.45)`
- 高光：按钮左上角小白色高光
- 装饰：猫爪印、藤蔓、木纹、星光、火光

## 4. 页面模板

### 4.1 通用页面结构

竖屏页面从上到下：

1. 背景层：夜晚森林/室内/羊皮纸底。
2. 顶部操作层：返回、标题、帮助/关闭。
3. 主内容层：卡片、列表、战斗区域、展示角色。
4. 操作层：主按钮、刷新、领取、合成。
5. 导航层：底部 tab 或固定操作栏。
6. 弹层层：遮罩、弹窗、奖励、确认框。

### 4.2 登录页模板

参考：`登陆页面.png`

必须包含：

- 全屏夜晚营地背景。
- 游戏 logo：`猫猫背包守夜`。
- 主角猫咪与火堆。
- 大号黄色 `开始游戏` 按钮。
- 用户协议/隐私政策勾选。
- `16+ CADPA` 适龄提示。
- 健康游戏提示文案。

交互：

- 未勾选协议点击开始时，弹出轻提示。
- 勾选后进入主页面。

### 4.3 主页面模板

参考：`主页面.png`

必须包含：

- 顶部左侧玩家头像、名字、等级、经验条。
- 顶部资源栏：金币、钻石，加号入口。
- 右上设置按钮。
- 中部关卡牌：章节名、最高波次。
- 场景主角猫、营地、火堆。
- 右侧竖排入口：签到、任务、邮件、排行榜。
- 大号 `开始战斗` 按钮，消耗体力/闪电。
- 底部导航：商店、背包、战斗、天赋、宠物。

### 4.4 战斗准备模板

参考：`准备开始战斗.png`

必须包含：

- 关卡标题：章节 + 波次。
- 推荐战力。
- 战斗预览图：猫、怪物、宝箱。
- 我的战力。
- 背包武器 2 行网格。
- 大号 `开始战斗` 按钮。
- 协议勾选与适龄提示可复用登录页组件。

### 4.5 战斗页模板

参考：`战斗.png`

必须包含：

- 顶部波次、倒计时、暂停按钮。
- 生命/进度条。
- 左侧猫咪角色，右侧怪物群。
- 子弹、伤害数字、命中特效。
- 中下火堆作为视觉中心。
- 底部武器栏：5 个武器槽 + 自动合成按钮。
- 武器冷却条。

交互：

- 点击暂停打开设置/继续弹窗。
- 武器冷却完成自动攻击。
- 自动合成按钮控制背包同类武器合成。

### 4.6 背包模板

参考：`背包.png`

必须包含：

- 顶部木牌标题和关闭。
- 页签：1、2、3、锁定页。
- 5 列物品网格。
- 选中态黄色发光。
- 右下数量徽章。
- 底部详情区域：图标、名称、等级、属性、描述。
- 操作按钮：合成、开箱。

### 4.7 合成提示模板

参考：`合成提示.png`

必须包含：

- 教学遮罩/弹窗结构。
- 背包网格示意。
- 两个同类装备发光，箭头指示拖拽/合成。
- `合成成功！` 大字光效。
- 合成结果卡片：武器图标、等级、攻击力、攻速、加成。
- `知道了` 主按钮。

### 4.8 商店模板

参考：`商店.png`

必须包含：

- 顶部资源栏：金币、紫钻、蓝钻。
- 中部木牌标题 `商店`。
- 页签：每日商店、钻石商店、特惠礼包。
- 三列商品卡。
- 商品图标、名称、数量、价格。
- 免费商品和广告刷新。
- 刷新倒计时。
- 底部导航。

### 4.9 宠物模板

参考：`宠物.png`、`宠物详情.png`

必须包含：

- 宠物大图展示。
- 品质徽章、名称、等级、星级。
- 属性列表：攻击、生命、防御、暴击率、暴击伤害。
- 升级材料进度条。
- 宠物列表卡片，出战中标签。
- 锁定卡显示解锁条件。

### 4.10 技能模板

参考：`技能.png`

必须包含：

- 局内 `选择一个技能` 横幅。
- 三张技能卡：名称、圆形图标、效果、星级、选择按钮。
- 底部刷新按钮，显示广告图标或钻石消耗。
- 背景保留战斗营地暗色氛围。

### 4.11 天赋模板

参考：`天赋.png`

必须包含：

- 顶部木牌标题。
- 分类页签：攻击、防御、通用。
- 天赋节点树：3 列多行。
- 已升级节点金色发光，未升级灰暗。
- 节点连线。
- 底部剩余点数和重置按钮。

### 4.12 任务/成就/邮件/设置/胜利模板

每日任务：

- 活跃度进度和宝箱节点。
- 任务卡列表：标题、进度条、奖励、前往/领取。
- 每日 0 点刷新提示。

成就：

- 成就卡列表：徽章、标题、条件、进度、奖励、领取/前往。
- 底部总进度、一键领取。

邮件：

- 左侧邮件列表，右侧详情。
- 附件奖励栏。
- 一键领取、一键删除。

设置：

- 音乐、音效、震动、省电模式开关。
- 兑换码、用户协议、隐私政策、帮助中心、联系客服。
- 当前版本号。

胜利：

- 大横幅 `胜利`。
- 三颗星。
- 猫咪和宝箱奖励场景。
- 奖励卡片列表。
- 双倍领取、确定按钮。

## 7. 给多 Agent 的统一执行约束

所有 Agent 必须遵守：

- 以 `C:/Users/User/Desktop/ima` 作为正式设计图源。
- 先做 MVP 可运行版本，再逐步替换精细切图。
- 微信小游戏使用 `game.js` 入口和 Canvas，不要做成普通小程序页面。
- 不要生成需要复杂安装的框架项目。
- 不要把 UI、数据、战斗逻辑全部写进一个文件。
- 每个模块必须能被其他 Agent import。
- 没有真实切图时，UIAgent 用 Canvas 绘制近似组件，并通过资源索引保留替换口。

## 8. 验收标准

第一阶段 MVP 验收：

- 微信开发者工具能导入 `CatBackpackNight`。
- 登录页能进入主页面。
- 主页面能进入准备战斗。
- 准备页能进入战斗。
- 战斗能自动攻击并结算胜利。
- 背包能选择物品并合成。
- 商店能购买商品并扣除货币。
- 宠物能升级和出战。
- 每日任务/成就能领取奖励。
- 邮件能查看和领取附件。
- 设置开关能保存。

第二阶段视觉验收：

- 页面结构与参考图一致。
- 主要按钮、卡片、标题、导航风格统一。
- 适配不同手机高度时内容不重叠。
- 红点、选中态、领取态、锁定态清晰。
- 关键奖励和合成有发光动画。
